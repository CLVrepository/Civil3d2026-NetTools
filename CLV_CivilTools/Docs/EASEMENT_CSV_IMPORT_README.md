# EASEMENT IMPORT

The `EASEMENT IMPORT` command imports standalone Prompt Easement CSV files.

Palette label: `EASEMENT IMPORT`

Command: `CLV_4_EASEMENT_IMPORT`

Prompt Easement remains standalone and builds from POC -> POB -> easement boundary calls. It does not require Prompt 1 sectional/control geometry.

The importer supports `Type=LINE`, `Type=CURVE`, and `Type=POINT_MARKER` with `ImportRole=COMMENCEMENT`, `EASEMENT`, `POC_MARKER`, or `POB_MARKER`.
