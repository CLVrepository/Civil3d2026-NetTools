# ROADS IMPORT

The `ROADS IMPORT` command imports Prompt 3 road centerline-only CSV files.

Palette label: `ROADS IMPORT`

Command: `CLV_3_ROADS_IMPORT`

Prompt 3 now uses the Prompt 2 boundary/tie/POC framework. It does not depend on Prompt 1 sectional/control linework.

Only centerline geometry is imported. Road edges, ROW outlines, offsets, cul-de-sac edge geometry, and curb returns are skipped or kept as notes for later tools.
