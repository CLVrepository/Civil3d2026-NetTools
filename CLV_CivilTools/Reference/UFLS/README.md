# UFLS Reference Material

## PIPE MATERIALS.xlsm

`PIPE MATERIALS.xlsm` is an engineering/reference workbook used during UFLS development to establish pipe-material and related command behavior.

It is **reference/provenance material only** and is not a runtime dependency of CLV Civil Tools. UFLS command logic is implemented in the managed application code; the application does not require this workbook to be present in order to run.

If the engineering reference is revised in the future, compare the revised workbook with the current UFLS implementation and update the application only where the documented engineering rules have changed.

The source workbook is retained in the project reference archive so the origin of the implemented UFLS material rules remains traceable.
