MAP TRANSFORM HISTORY R3 TEST BUILD
===================================

The main-project bin/obj artifacts are intentionally excluded from this package so the revised source must be rebuilt.

1. Open CLV_CivilTools.csproj / solution in Visual Studio.
2. Rebuild CLV_CivilTools for net8.0-windows x64.
3. Deploy/NETLOAD the newly built CLV_CivilTools.dll using your normal Civil 3D loading workflow.
4. Run MAP TRANSFORM. BEFORE the map-selection prompt you must see:
   MAP TRANSFORM revision 2026.08.06-HISTORY-R3.
5. Create/finalize a transform and confirm:
   Saved and verified editable Map Transform history with N point pair(s).
6. Run MAP TRANSFORM again and select the same map reference.
   - The saved pairs should be recalled.
   - The map should temporarily return to its original pre-transform location while editing.
   - Numbered pair markers (1, 2, 3, etc.) should reappear on both Survey and Map picks.
7. Click Add Pair and select one more Survey/Map pair. The new residual should be on the same coordinate basis as the original pair collection, not offset by the prior map translation.
8. Cancel an edit session and confirm the map returns to the transformed placement it had before the command started.
9. Apply an updated transform and confirm the map is rebuilt from the stored original placement.

If step 4 does not show the R3 revision line, Civil 3D is still running an older DLL.
