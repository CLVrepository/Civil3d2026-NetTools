# Tools and Command Context

This file supplements the actual HTML pages in the Knowledge Base. The website files remain useful for the detailed baseline tool list.

## CLV MENU
The baseline includes links/utilities for City applications, coordinate systems, CAD support, survey database resources, field photos, web services, and design standards.

Examples in the baseline include Benchmarks, CLV GIS, Content Manager, Infor, NV83 coordinate-system helpers, Update Alias, Reload Ribbon, Survey Projects/Technical Reviews, Import/View Photos, GISMO, Google Maps, Recorder's Office, and design-standard links.

## Q1 / UFLS
Known functions include verification/highlight tools, redline tools, 2D/3D utility linework creation, structure helpers, invert labeling, and PIPE INFO @ POINT.

Important named commands/workflows include:
- HIGHLIGHT RED / GREEN
- OBJECT HIGHLIGHT RED / GREEN
- PIPE INFO @ POINT
- manhole/structure linework tools
- TOP OF PIPE / TRIM TOP OF PIPE / LABEL INVERT

## GIS
The baseline Knowledge Base includes GIS import, centerline joins, address/parcel location, survey-report/OD inspection and related GIS workflows.

## Point Cloud
The baseline includes crop/uncrop, rotate/UCS, tracing, vertex tools, sample-line helpers, manhole/structure workflows, and related quick tips.

## Survey / Mapping / Labels
Important workflows include:
- MAP TRANSFORM (newer name; older baseline may say BEST FIT MAP)
- BOUNDARY / closure/review tools
- BOUNDARY TRANSFORM
- survey legend CREATE / UPDATE
- roadway labels
- distance/offset/angle/radius dimensions
- PLSS section labels / section reference tools
