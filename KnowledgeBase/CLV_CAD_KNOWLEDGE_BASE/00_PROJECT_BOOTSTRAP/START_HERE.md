# CLV CAD Knowledge Base — Bootstrap

**Migration package:** 2026-08-24  
**Baseline Knowledge Base snapshot:** 2026-06-15

This folder carries durable ChatGPT project context for moving the CLV CAD Knowledge Base project to another account. The rest of this ZIP is the existing Knowledge Base website snapshot and reference assets.

## Recommended setup on the new ChatGPT account

1. Create a new Project named **CLV CAD Knowledge Base**.
2. Upload this ZIP to the Project.
3. Paste the contents of `MIGRATION_PROMPT.md` into the first chat.
4. If the account supports Project Instructions, use `PROJECT_INSTRUCTIONS.md` as the starting instructions.
5. Keep this package as durable context. New source code, screenshots, drawings, standards, or later decisions may supersede it.

1. `PROJECT_INSTRUCTIONS.md`
