Q1 UFLS Tools workflow page.

1P MANHOLE - ALL

Creates manhole linework from a single AEC point identifying center of structure. When using CLV surveyed data, the codes used are automatic and the diameter of block used will auto identify. When using others data, input the code manually since it varies from firm to firm.

Basic Use

  1. Open the Q1 UFLS Tools menu and go to the related CHECK tab.
  2. Select 1P MANHOLE - ALL.
  3. Follow the command prompts in order.
  4. Review the created or modified linework/network object before continuing.
