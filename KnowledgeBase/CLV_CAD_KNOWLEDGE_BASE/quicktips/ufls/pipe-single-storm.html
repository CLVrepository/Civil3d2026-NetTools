Q1 UFLS Tools workflow page.

PIPE - SINGLE STORM

Moves the selected pipe to match the 3D polyline created using the UFLS tools. 3D linework must be generated using the UFLS tools.

Basic Use

  1. Open the Q1 UFLS Tools menu and go to the related ADJUST tab.
  2. Select PIPE - SINGLE STORM.
  3. Follow the command prompts in order.
  4. Review the created or modified linework/network object before continuing.
