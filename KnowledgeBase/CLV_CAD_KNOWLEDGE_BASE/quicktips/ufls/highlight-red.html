How To: HIGHLIGHT RED

Q1 UFLS Tools workflow page.

HIGHLIGHT RED

Highlights selected verification items in red for review and correction tracking.

Basic Use

  1. Open Q1 UFLS Tools and go to CHECK.
  2. Select HIGHLIGHT RED.
  3. Select the items that need to be flagged.
  4. Review the highlighted objects before moving on.

Related: Use OBJECT HIGHLIGHT RED when you need to highlight individual selected CAD objects from the Q1 CHECK tab.
