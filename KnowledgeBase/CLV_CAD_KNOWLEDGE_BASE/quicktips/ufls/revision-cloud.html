How To: REVISION CLOUD

Q1 UFLS Tools workflow page.

REVISION CLOUD

Creates a revision cloud for redline review. The command prompts for Large, Medium, or Small cloud size before starting the revision cloud routine.

Basic Use

  1. Open Q1 UFLS Tools and go to CHECK.
  2. Select REVISION CLOUD.
  3. Choose the cloud size: Large, Medium, or Small.
  4. Place the cloud around the area that needs review.
