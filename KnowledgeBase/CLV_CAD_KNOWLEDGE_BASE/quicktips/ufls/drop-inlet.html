How To: DROP INLET

Q1 UFLS Tools workflow page.

DROP INLET

Places a drop inlet structure block. User is prompted for structure type, structure size, and depth of structure. User is prompted for 2 point back-of-curb shots only or 4 point outer limits of structure to identify block placement. User is also prompted for a pick direction; select the direction of the centerline of road.

Basic Use

  1. Open the Q1 UFLS Tools menu and go to the related CHECK tab.
  2. Select DROP INLET.
  3. Follow the command prompts in order.
  4. Review the created or modified linework/network object before continuing.
