How To: OBJECT HIGHLIGHT RED

Q1 UFLS Tools workflow page.

OBJECT HIGHLIGHT RED

Highlights individually selected objects in red when only specific CAD objects need to be flagged for review.

Basic Use

  1. Open Q1 UFLS Tools and go to CHECK.
  2. Select OBJECT HIGHLIGHT RED.
  3. Select the individual object or objects that need to be flagged.
  4. Review the highlighted object results before moving on.
