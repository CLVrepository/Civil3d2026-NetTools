How To: TOP CHECK

Q1 UFLS / Pipe Top Check workflow.

TOP CHECK

Use TOP CHECK to compare the surveyed top-of-pipe elevation at a COGO point with the calculated Civil 3D pipe top.

Label result:
PLAN - TOP = elevation
SURV - TOP = elevation
DIFF = +/- difference

Basic Use

  1. Open Q1 UFLS Tools and select TOP CHECK → ELEVATION COMPARISON.
  2. Select the Civil 3D COGO point representing the surveyed elevation.
  3. Select the Civil 3D pipe being checked.
  4. Specify the label location.
  5. Review the PLAN, SURV, and DIFF values.

Tolerance Review

  1. Select EXCEEDS TOLERANCE.
  2. Enter the tolerance when prompted; the default is 0.30.
  3. Over-tolerance checks receive exhibit IDs and can be displayed as compact numbers.
  4. Use DETAILS to restore the full label or NUMBERS for exhibit-number display.

Tables

  • ADD TABLE creates a table from selected TOP CHECK labels.
  • ADD POINTS adds additional checks to an existing table.
  • REMOVE POINTS removes checks from an existing table.
  • SCALE TABLE updates the table to the current annotation scale.
Important: Do not recreate TOP CHECK labels as plain MText. The command stores structured check data on the label so tolerance, table, and exhibit workflows can use it later.
