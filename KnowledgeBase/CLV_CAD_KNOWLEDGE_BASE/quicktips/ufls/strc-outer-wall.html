How To: STRC-OUTER WALL

Q1 UFLS Tools workflow page.

STRC-OUTER WALL

Creates outer wall linework for a structure. Prompts for point selection and structure type to identify the correct wall thickness. Once done, the inner wall offset happens automatically.

Basic Use

  1. Open the Q1 UFLS Tools menu and go to the related CHECK tab.
  2. Select STRC-OUTER WALL.
  3. Follow the command prompts in order.
  4. Review the created or modified linework/network object before continuing.
