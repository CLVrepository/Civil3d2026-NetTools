Join Centerlines

When GIS centerline data is brought in, the centerlines are separated out as the accessor creates them. This tool allows the user to select each segment of the centerline and joins them automatically, and attempts to retain the object data that is assigned.

Basic Use

  1. Open the Q2 GIS + Aerials menu.
  2. Go to GIS Tools.
  3. Select Join Centerlines.
  4. Pick the centerline segments in the required order.
  5. Allow the tool to join the selected segments.
  6. Inspect the joined centerline and verify the retained object data.
