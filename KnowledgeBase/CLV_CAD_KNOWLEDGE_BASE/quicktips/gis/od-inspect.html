OD Inspect

When Survey GIS data is created, the objects are tagged with XDATA. After selecting tool, select the Survey GIS object you want to see the XDATA for. County GIS data does not contain XDATA.

Basic Use

  1. Open the Q2 GIS + Aerials menu.
  2. Go to XData.
  3. Select OD Inspect.
  4. Select the Survey GIS object to inspect.
  5. Review the displayed XDATA information.
  6. Use this only for GIS data created by the Survey Department.
