Q3 Point Cloud Tools workflow page.

STEP 1 - CROP POINT CLOUD

Crops point cloud to the user selected area.

Basic Use

  1. Open the Q3 Point Cloud Tools menu and go to the UFLS tab.
  2. Select STEP 1 - CROP POINT CLOUD.
  3. Follow the command prompts in order.
  4. Review the point cloud crop, view, or created geometry before continuing.
