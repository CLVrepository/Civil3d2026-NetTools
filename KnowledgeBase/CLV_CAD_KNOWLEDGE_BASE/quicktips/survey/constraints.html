Survey + Mapping / BOUNDARY workflow page.

CONSTRAINTS

Defines closure constraints so selected boundary segments, bearings, distances, curves, or control points can be held during closure adjustment.

Basic Use

  1. Open Q4 Survey + Mapping and go to MAPPING.
  2. Select CONSTRAINTS.
  3. Choose the linework, curve, point, or segment information that should remain fixed during adjustment.
  4. Save or apply the constraint settings.
  5. Run AUTO CLOSURE or review the closure setup with the selected constraints in place.
