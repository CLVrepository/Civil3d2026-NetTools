How To: MAP TRANSFORM

Q4 Survey + Mapping / MAPPING workflow.

MAP TRANSFORM

Transforms selected mapping linework so it fits surveyed control. Use this tool when the mapping data and surveyed data represent the same features, but the mapping needs to be shifted, rotated, or best-fit adjusted to the surveyed location.

Result: The selected map linework is transformed to the surveyed control location, and a BestFit XML file is written to the same folder as the active CAD drawing.
Important pick order: After starting the tool, select the map linework first. For each control pair, pick the survey / destination point first, then pick the matching map / starting point.

Basic Use

  1. Open the drawing and confirm the map linework and surveyed control points are visible.
  2. Open Q4 Survey + Mapping, go to MAPPING, and select MAP TRANSFORM under TRANSFORM.
  3. Select the map linework that needs to be transformed.
  4. For each control pair, pick the survey / destination point first and the matching map / starting point second.
  5. Review the transform results and include or exclude control pairs as needed.
  6. Select Finalize Move when the results are acceptable.

Notes

  • Use well-distributed matching points when possible.
  • If one control pair produces a poor error result, exclude it and review the fit before finalizing.
  • The BestFit XML output provides a saved record of the transform setup/results.
  • MAP TRANSFORM is the current name for the older BEST FIT MAP workflow. The filename of this guide remains best-fit-map.html so existing bookmarks do not break.
