How To: DISTANCE

Survey + Mapping / DIMENSIONS workflow page.

DISTANCE

Basic Use

  1. Open Q4 Survey + Mapping and go to LABEL.
  2. Select DISTANCE.
  3. Pick the start point and end point for the distance to dimension.
  4. Place the dimension where it reads clearly.
  5. Review the dimension text, layer, and style before final plotting or review.

Tip: The clip is set to repeat so users can watch the pick order without restarting the video.
