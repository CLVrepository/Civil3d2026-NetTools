How To: CREATE LEGEND

Q4 Survey + Mapping / LABEL survey legend workflow.

CREATE LEGEND

Use this command to insert a new approved survey legend in the current drawing.

Basic workflow

  1. Open Q4 Survey + Mapping and go to the LABEL tab.
  2. Select CREATE LEGEND.
  3. Pick the legend insertion point in the drawing.
  4. The routine inserts SURV_LEG_HEADER first, then inserts the approved legend blocks in sort order.
  5. Review the completed legend and move it as needed for the sheet layout.

Legend standard

  • Legend content is controlled by the approved SurveyLegend.csv reference list.
  • Blocks are pulled from the Survey Legend block folder on the CAD support server.
  • Spacing is applied downward from each block insertion point using the configured single and double spacing values.
