How To: IMPORT LABELS

Q4 Survey + Mapping / LABEL PLSS section label workflow.

IMPORT LABELS

Imports PLSS section labels into a selected area of the drawing using the approved section label blocks.

Basic Use

  1. Open the Q4 Survey + Mapping menu.
  2. Go to the LABEL tab.
  3. In the PLSS SECTIONS section, select IMPORT LABELS.
  4. Select an area or select a closed object, such as a polyline, to define the label import limits.
  5. The tool reads the section reference data for the current coordinate system and inserts the matching section label blocks.
  6. Review the inserted labels. Section numbers are displayed with the S prefix, and single-digit sections display without a leading zero.

Note: Labels are inserted at the current drawing scale at the time the command is run.
