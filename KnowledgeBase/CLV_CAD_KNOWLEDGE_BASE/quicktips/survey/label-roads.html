How To: STREET NAMES

Q4 Survey + Mapping roadway label workflow.

STREET NAMES

Creates roadway name labels from GIS street centerline data. The project must be geolocated and have the correct coordinate system assigned before running this command.

Result: Roadway labels are created from available GIS data inside the selected boundary area. Some cleanup may still be required, such as removing duplicate labels or adjusting labels that do not land in the preferred location.
Critical setting: In the Convert Labels to Text dialog, set Selection Scope to Labels within the view window. Do not leave it set to the full data set, or Civil 3D may attempt to create labels for the entire GIS data set.

Before You Start

  1. Confirm the drawing is geolocated.
  2. Confirm the correct coordinate system is assigned.
  3. Zoom near the project area where labels are needed.
  4. Use a boundary that covers the desired label area only.
  5. Be ready to set the label conversion target layer to C-ROAD-LABL.

Workflow

  1. Open Q4 Survey + Mapping and select STREET NAMES under LABEL → ROADWAY.
  2. Choose the appropriate boundary mode and identify the desired label area.
  3. Verify the view window contains only the area that should be converted.
  4. Continue to the Convert Labels to Text dialog.
  5. Set Select the Target to C-ROAD-LABL.
  6. Set Selection Scope to Labels within the view window.
  7. Review the resulting street-name text and clean up duplicates or placement as needed.

Notes

  • If no GIS road data exists inside the selected area, no roadway labels will be created.
  • The command is intended to speed up roadway labeling, not replace final drafting review.
  • Verify text height, layer, and label locations before plotting or issuing drawings.
  • STREET NAMES is the current palette name for the older LABEL ROADS workflow. The filename remains label-roads.html so existing bookmarks do not break.
