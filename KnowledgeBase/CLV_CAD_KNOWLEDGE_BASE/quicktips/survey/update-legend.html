How To: UPDATE LEGEND

Q4 Survey + Mapping / LABEL survey legend workflow.

UPDATE LEGEND

Use this command to refresh an existing approved survey legend after the block list, order, or spacing requirements have changed.

Basic workflow

  1. Open Q4 Survey + Mapping and go to the LABEL tab.
  2. Select UPDATE LEGEND.
  3. Select the existing survey legend to update when prompted.
  4. The routine rebuilds or refreshes the legend using the approved legend block list, sort order, and spacing rules.
  5. Review the updated legend for placement and confirm it still fits the sheet layout.

When to use

  • Use after legend blocks or descriptions have been revised.
  • Use when an older survey legend needs to match the current standard.
  • Use instead of manually editing legend spacing or block order.
