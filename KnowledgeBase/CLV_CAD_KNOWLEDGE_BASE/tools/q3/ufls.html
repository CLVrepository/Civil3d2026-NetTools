UFLS

Point cloud UFLS pipe locator, structure linework, view control, and crop tools.

POINT CLOUD DISPLAY

Point cloud attachment and visibility controls.

Tool
Purpose
ATTACH
Attaches point cloud data to the drawing.
INTENSITY
Displays point cloud data using intensity display settings.
TRANSPARENCY
Adjusts point cloud transparency for better linework visibility.
ON
Turns point cloud display on.
OFF
Turns point cloud display off.

PIPE LOCATOR

Step-based pipe tracing workflow from point cloud data.

Tool
Purpose
STEP 1 - CROP POINT CLOUD
Crops point cloud to the user selected area.
HOW TO
STEP 2 - ROTATE VIEW
Rotates cropped point cloud via user controls to cross section the pipe.
HOW TO
STEP 3 - SET UCS
Sets the UCS view to the current rotation.
HOW TO
STEP 4 - TRACE PIPE
Allows the user to select the inner wall of the pipe, and places a pipe block at that location. Block reads pipe size and correctly places the correctly sized block. Then places an AEC point to identify the top of pipe.
HOW TO
STEP 5 - RESET VIEW
Resets the UCS and visual style to plan view.
HOW TO

2D LINEWORK

Creates UFLS structure geometry from point cloud data.

Tool
Purpose
STRC-INNER WALL
Creates structure inner wall linework from picked locations. Allows user to select structure type to generate the outer wall.
HOW TO
LOCATE MANHOLE
Identifies the center of structure and places a correctly sized block based on point cloud data selected by the user.
HOW TO
3P CIRCLE
Creates circular linework from three picked points.
3P RECTANGLE
Creates rectangular linework from picked points.

VIEW CONTROL

View rotation and reset controls.

Tool
Purpose
3D ROTATE
3D rotate command which saves the before state. This allows the user to reset back to this location when running RESET VIEW.
HOW TO
RESET VIEW
Resets the view after running the 3D ROTATE command.

QUICK CROP

Quick point cloud crop controls for UFLS review.

Tool
Purpose
CROP
Crops the point cloud to the selected UFLS review area.
HOW TO
UNCROP
Removes the active crop and restores the point cloud display.
