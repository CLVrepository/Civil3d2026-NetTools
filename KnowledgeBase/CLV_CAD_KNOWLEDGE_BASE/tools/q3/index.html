Q3 MENU

ROADWAY

Point cloud roadway review, sample line, crop, cross section, view control, point movement, and polyline tools.

POINT CLOUD DISPLAY

Point cloud attachment and visibility controls.

Tool
Purpose
ATTACH
Attaches point cloud data to the drawing.
INTENSITY
Displays point cloud data using intensity display settings.
TRANSPARENCY
Adjusts point cloud transparency for better linework visibility.
ON
Turns point cloud display on.
OFF
Turns point cloud display off.

SAMPLE LINES

Creates sample lines for roadway review.

Tool
Purpose
CREATE SAMPLE LINES
Creates sample lines used for roadway point cloud review and cross section workflows.
HOW TO

CROP SAMPLE LINES

Crops or uncrops point cloud areas using sample lines.

Tool
Purpose
CROP SL
Crops the point cloud to the selected sample line area.
HOW TO
UNCROP SL
Removes the sample line crop and restores the point cloud display.
HOW TO

QUICK SAMPLE LINE

Creates and uses a temporary sample line.

Tool
Purpose
QUICK SL
Allows user to select two points and creates a temporary sample line based on the points picked. Will prompt user and crop point cloud accordingly.
HOW TO
UNCROP SL
Removes the sample line crop and restores the point cloud display.
HOW TO

GENERAL CROP

General point cloud crop controls.

Tool
Purpose
CROP
Crops the point cloud to the selected area.
HOW TO
UNCROP
Removes the active crop and restores the point cloud display.
HOW TO

CROSS SECTION

Crops and rotates the view for cross section review.

Tool
Purpose
CROSS SECTION
Crops point cloud to the sample line area selected, and rotates the view to allow user to select points as needed.
HOW TO
RESET CS
Resets view when done with the CROSS SECTION review.

VIEW CONTROL

View rotation and reset controls.

Tool
Purpose
3D ROTATE
3D rotate command which saves the before state. This allows the user to reset back to this location when running RESET VIEW.
HOW TO
RESET VIEW
Resets the view after running the 3D ROTATE command.

MOVE POINTS

Moves AEC points to selected linework or vertices.

Tool
Purpose
TO SAMPLE LINE
Moves AEC points to selected cross section line. Typically used when creating points via the CROSS SECTION tool.
HOW TO
MOVE POINTS TO VERTEX
Moves AEC points to the closest vertex in a polyline.
HOW TO

MOVE POINTS & ADD VERTICES

Moves points and adds vertices to polyline geometry.

Tool
Purpose
SINGLE/MULTIPLE
Moves selected AEC points to the closest polyline, adds vertex locations as needed.
HOW TO
ADJACENT
Moves selected AEC points to the closest vertex of the selected polyline, and then adds the same vertex points to the selected adjacent polylines.
HOW TO

POLYLINE TOOLS

Polyline cleanup and vertex marking tools.

Tool
Purpose
COPY VERTEX FROM PL TO PL
Allows user to select a polyline, and copy vertex location to other selected polyline.
HOW TO
ADD VERTEX @ CROSSING
Allows user to automatically add vertex point locations to polyline at all selected crossing line intersection points.
HOW TO
IDENTIFY VERTICES
Places temporary marker at all polyline vertex locations. Can be removed globally by typing DX.
HOW TO
GENERAL MARKER
Places a general marker point, helpful for identifying grade breaks or elevation information such as pipe inverts.
