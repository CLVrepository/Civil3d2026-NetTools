Q2 MENU

GIS

Address and parcel locating, GIS imports, coordinate zone overlays, PLSS section overlays, GIS cleanup tools, and Survey GIS XData inspection.

ADDRESS

Locate project areas by address, intersection, parcel number, or owner name.

Tool
Purpose
LOCATE ADDRESS
Allows user to specify address or intersection. Will give options when solutions found, and will then zoom to the location and turn on Bing Maps.
HOW TO
LOCATE PARCEL
Allows user to specify parcel number or owner name. Will give options when solutions found, and will zoom to the location, highlight selected property, and turn on Bing Maps.
HOW TO

DATA

Import GIS data or open the restricted data creation tool set.

Tool
Purpose
IMPORT GIS
Allows user to import GIS data. Once dialog box opens the user can specify what type of data to import.
HOW TO
CREATE DATA
This opens a tool set used to create GIS data sets. This is a restricted tool set, only certain users have access.

SECTION/COORDINATE SYSTEM

Displays or unloads reference overlays for City coordinate zones and PLSS section information.

Tool
Purpose
DISPLAY COORDINATE ZONES
Displays the City coordinate zone reference overlay so users can verify whether the project area falls within the LVF or LVHEF coordinate system area.
UNLOAD COORDINATE ZONES
Unloads the coordinate zone reference overlay from the drawing.
DISPLAY SECTIONS
Displays the TOWNSHIP/RANGE map.
UNLOAD SECTIONS
Unloads the TOWNSHIP/RANGE map.

GIS TOOLS

Centerline cleanup and Survey GIS report tools.

Tool
Purpose
HTML SURVEY REPORT
This is a report document for the Survey GIS data that has been added. It is broken out via Sewer, Storm, and project number. It is a searchable document.
Note: This data is mainly populated as new project data is collected per UFLS surveys. Older data sets may not be available. If specific data is desired, a request can be put in to the Survey Department.
HOW TO

XDATA

Inspect Survey GIS object tags created by the Survey Department workflow.

Tool
Purpose
OD INSPECT
When Survey GIS data is created, the objects are tagged with XDATA. After selecting tool, select the Survey GIS object you want to see the XDATA for. County GIS data does not contain XDATA. This is only available for GIS data that the Survey Department creates.
HOW TO
