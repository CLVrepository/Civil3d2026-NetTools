Q4 MAPPING · TOOLS

LEGAL DESCRIPTION

Build, review, edit, save, and export a legal description from a connected traverse of AutoCAD LINE and ARC entities.

STARTING THE BUILDER

  1. Run LEGALDESC / CLV-LEGAL-DESCRIPTION.
  2. Select one connected traverse made from individual AutoCAD LINE and ARC entities.
  3. Choose the desired Point of Beginning endpoint.
  4. Optionally identify a separate Point of Commencement.
  5. Review the resulting legal-description palette.

Reopen: LEGALDESC-OPEN reopens the most recently saved legal-description session stored in the current drawing.

GEOMETRY AND REVIEW

The builder orders an unordered LINE/ARC selection into a connected traverse using a 0.10-foot endpoint tolerance while preserving the original source entities.

  • Line bearings and distances are calculated.
  • Curve direction, radius, central angle, and arc length are calculated.
  • The complete traverse can be reversed from the palette.
  • Traverse length and enclosed area are reported.
  • Forward misclosure and an independently sequenced reverse-direction build result are reported.
  • Selecting a course row highlights its source entity; SELECT / ZOOM COURSE centers the view on that course.

TEXT EDITOR

Each course can be edited individually before the final legal wording is generated.

  • Include or exclude a course.
  • Edit prefix, along/context wording, and suffix.
  • Use a complete geometry-text override when needed.
  • REGENERATE TEXT rebuilds the legal text from the course data.
  • The full preview remains editable for final wording.
  • SAVE TO DRAWING stores the complete session and edited text in the drawing.
  • EXPORT TXT writes the displayed description to a text file.

CAD REVIEW AND LINKED MTEXT

The drawing can store the editable legal-description session and maintain linked MText as the live CAD review copy. Use the linked MText workflow to review the final paragraph-form legal description in the drawing before export.

EXPORT LEGAL DOCX

  1. Build and review the legal description in the palette editor.
  2. Place or update linked MText for CAD review.
  3. Select EXPORT LEGAL DOCX.
  4. Confirm APN, date, preparer, peer reviewer, explanation, basis of bearings, and exhibit statement.
  5. Select the output .docx path.

The exported DOCX is the formatted City Surveyor deliverable. Word does not need to be running for the export. Open the finished DOCX for final page-layout review before issuance.

CURRENT SCOPE AND LIMITATIONS

  • Input geometry must be one connected traverse of individual LINE and ARC entities.
  • Polylines, splines, ellipses, Civil 3D parcels, and alignment entities are not converted by this workflow.
  • A separate POC can be recorded and identified in the opening wording, but the current Phase 1-2 workflow does not automatically calculate or write the commencement tie from POC to POB.
  • Street names, intersections, PLSS callouts, monument descriptions, record documents, and adjoining ownership are entered manually through the available context or override fields.
  • Generated wording is a drafting aid and requires review by the responsible survey/legal professional.
