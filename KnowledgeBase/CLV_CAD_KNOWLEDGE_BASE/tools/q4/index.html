LABEL

Roadway labeling, dimension tools, survey legend tools, and PLSS section label tools for survey and mapping workflows.

ROADWAY

Roadway name labeling tools.

Tool
Purpose
LABEL ROADS
Allows user to create roadway name labels. Project must be geo located and have coordinate system assigned. User will define a boundary area, roadway labels will auto create. In the conversion dialog, target C-ROAD-LABL and set Selection Scope to Labels within the view window to avoid processing the full GIS data set. Since created from GIS data, some cleanup will be needed, such as removing duplicate labels. Will only create labels if GIS has data in the area. If no data exists, no labels will be created.

LEGEND

Survey legend creation and update tools.

Tool
Purpose
CREATE LEGEND
Creates a survey legend in the drawing from the approved survey legend block list. Insert the legend header first, then place legend blocks in the configured sort order with the correct single and double spacing.
HOW TO
UPDATE LEGEND
Updates an existing survey legend to match the current approved legend block list, order, and spacing standards.
HOW TO

PLSS SECTIONS

Imports PLSS section labels into the current drawing using the approved section label blocks and current drawing scale.

Tool
Purpose
IMPORT LABELS
Imports section labels for a selected area or selected closed object. Labels are inserted from the approved PLSS section label blocks, use the current drawing scale, and display section numbers with the S prefix.
