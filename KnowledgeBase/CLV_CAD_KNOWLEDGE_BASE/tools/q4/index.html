LABEL

Roadway labeling, dimension tools, line and curve labels, area labels, survey legend tools, and PLSS section label tools for survey and mapping workflows.

ROADWAY

Roadway name labeling tools.

Tool
Purpose
STREET NAMES
Creates roadway name labels from available GIS data within a user-defined boundary. The drawing must be geo-located and have a coordinate system assigned. Because the labels are created from GIS data, some cleanup such as duplicate-label removal may be required.

DIMENSIONS

Dimension creation tools.

Tool
Purpose
DISTANCE
Creates an aligned distance dimension using the approved CLV dimension style and layer settings.
HOW TO
OFFSET
Creates an aligned dimension between 2 objects. Useful for items such as sidewalk width.
HOW TO
ANGLE - DEGREES
Creates angular dimensions displayed in decimal degrees.
HOW TO
ANGLE - SECONDS
Creates angular dimensions displayed in degrees, minutes, and seconds.
HOW TO
RADIUS
Creates radius dimensions for arcs and curves.

LINES AND CURVES

Civil 3D line and curve labeling tools used for survey linework annotation.

Tool
Purpose
2-POINT || BEARING AND DIST
Runs the Civil 3D line-between-two-points label workflow using the approved CLV bearing-and-distance label settings.
2-POINT || DIST
Runs the Civil 3D line-between-two-points distance-label workflow using the approved CLV label settings.
BEARING AND DIST
Creates a single-segment bearing-and-distance label using the approved CLV survey label style.
DISTANCE
Creates a single-segment distance label using the approved CLV survey label settings.

These tools manage the CLV V-LABL layer around the native Civil 3D labeling commands and restore the user's previous current layer after the workflow.

AREA

Area labeling tools.

Tool
Purpose
AREA SF LABEL
Prompts for a point inside a closed boundary, traces the boundary, calculates its area, and places a centered square-foot MText label on the approved survey area label layer.

LEGEND

Survey legend creation and update tools.

Tool
Purpose
CREATE LEGEND
Creates a survey legend in the drawing from the approved survey legend block list.
HOW TO
UPDATE LEGEND
Updates an existing survey legend to match the current approved legend block list, order, and spacing standards.
HOW TO

PLSS SECTIONS

Imports PLSS section labels into the current drawing using the approved section label blocks and current drawing scale.

Tool
Purpose
IMPORT LABELS
Imports section labels for a selected area or selected closed object using the approved PLSS section label blocks.
