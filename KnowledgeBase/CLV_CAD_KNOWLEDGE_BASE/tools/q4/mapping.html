Q4 MENU

MAPPING

Transform, boundary review, mapping support, legal description, PDF, XREF, linework review, and subdivision drafting tools.

TRANSFORM

Tool
Purpose
MAP TRANSFORM
Transforms selected map linework to surveyed control using paired control points and a review step before finalizing the transformation.
BOUNDARY TRANSFORM
Transforms boundary linework to control using the current boundary/control workflow.
C3D TRANSFORM
Runs the Civil 3D transformation workflow used for supported drawing coordinate transformations.

Terminology: MAP TRANSFORM is the current name for the older BEST FIT MAP workflow. BOUNDARY TRANSFORM is the current name for the older TRANSFORM TO CONTROL workflow.

TOOLS

Tool
Purpose
DRAW TIE LINE
Starts the AutoCAD LINE workflow on the approved survey control-tie layer and restores the previous current layer when the command ends or is cancelled.
PDF VIEWER
Opens the CLV PDF viewer workflow for working with supported PDF references from within Civil 3D.
PDF CLIP
Runs the PDF clipping workflow for supported PDF underlays/references.
LEGAL DESCRIPTION
Builds and reviews a legal description from a connected LINE/ARC traverse and supports saved sessions, linked MText, TXT export, and DOCX export.
HELP
XREF COLOR
Applies the survey XREF color workflow to help standardize referenced survey drawing display.
OFFSET TO TEMP LAYER
Creates offset geometry on the temporary mapping workflow layer for review/drafting operations.
LINEWORK REVIEW
Starts the survey linework review workflow for identifying and reviewing mapping linework conditions.

BOUNDARY

Boundary closure and review tools. The current palette combines closure adjustment and review operations under BOUNDARY.

Tool
Purpose
AUTO CLOSURE
Runs the boundary closure workflow against selected boundary linework.
CONSTRAINTS
Defines and manages closure constraints used by the boundary adjustment workflow.
CLOSURE REPORT
Creates or opens the boundary closure report for review.
CLOSURE MARKERS
Places review markers at closure report segment locations.
GOTO SEGMENT
Navigates to a selected closure report segment for drawing review.
CLEAR REVIEW MARKERS
Removes temporary boundary review markers.

SUBDIVISION LINEWORK

First-pass subdivision drafting helpers driven from road centerlines and stored site settings.

Tool
Purpose
SITE SETTINGS
Sets typical road width, cul-de-sac radius, tie-in radius, and curb return radius.
ROADS
Offsets selected road centerlines to create road-edge geometry on V-MAPL-ROAD-ROW.
CUL-DE-SAC
Creates and cleans cul-de-sac bulb and tie-in geometry.
INTERSECTION
Creates curb-return geometry and cleans generated road-edge intersections.
LOT LINES
Creates repeated lot-line offsets at a specified spacing until a selected stop location is reached.
