Q4 MENU

MAPPING

Survey map, township/range reference, boundary closure, constraint, and review tools.

SURVEY MAP

Survey map preparation tools.

Tool
Purpose
BEST FIT MAP
Transforms selected map linework to surveyed control. Select the map linework first, then build each control pair by selecting the survey destination point followed by the matching map starting point. The review dialog allows control pairs to be checked or unchecked with live error updates before finalizing.
HOW TO

TOWNSHIP/RANGE

Township, range, and section corner reference tools used during survey mapping review.

Tool
Purpose
SECTION CORNER MARKER
Places the approved section corner marker for PLSS section corner review.

BOUNDARY

Boundary closure and adjustment tools.

Tool
Purpose
AUTO CLOSURE
Reviews selected boundary linework and creates an adjusted closure using the available closure settings and constraints.
HOW TO
CONSTRAINTS (BETA)
Development / beta tool for defining closure constraints so selected boundary segments, bearings, distances, curves, or control points can be held during closure adjustment.

REVIEW

Closure report and review navigation tools.

Tool
Purpose
CLOSURE REPORT
Creates or opens the closure report for the current boundary review.
CLOSURE MARKERS
Places review markers at closure report segment locations.
GOTO SEGMENT
Zooms to a selected closure report segment for review.
CLEAR REVIEW MARKERS
Removes temporary closure review markers from the drawing.
