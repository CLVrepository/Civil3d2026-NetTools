Q4 MAPPING · SUBDIVISION LINEWORK

SUBDIVISION LINEWORK

First-pass drafting helpers for generating subdivision linework from imported road centerlines. These tools are intended for review/testing and continue to evolve.

SITE SETTINGS

Sets the session defaults reused by the subdivision drafting tools.

  • Typical road width.
  • Cul-de-sac radius.
  • Cul-de-sac tie-in radius.
  • Curb return radius.

Command: CLV_SUBDIV_SITE_SETTINGS

ROADS

  1. Run SITE SETTINGS first and confirm the typical road width.
  2. Select the road centerline objects that use the same width.
  3. The tool offsets both sides of each selected centerline by half the typical road width.
  4. Road-edge geometry is created on V-MAPL-ROAD-ROW.

Source centerlines are not modified. Continuous centerline polylines generally produce the cleanest joined results. Separate line/curve pieces may require cleanup where objects meet.

Command: CLV_SUBDIV_ROADS

CUL-DE-SAC

  1. Run SITE SETTINGS or adjust the bulb values when prompted.
  2. Select the cul-de-sac road centerline and pick the endpoint/bulb center.
  3. Allow the tool to find nearby V-MAPL-ROAD-ROW road-edge geometry, or select the edge lines to clean when prompted.
  4. The tool creates/cleans the bulb and tie-in geometry using the stored radius settings.

The current workflow is designed first for simple line/arc/polyline centerlines. Complex compound or reverse curves should be reviewed after creation.

Command: CLV_SUBDIV_CULDESAC

INTERSECTION

  1. Confirm road width and curb return radius in SITE SETTINGS.
  2. Select the MAIN road centerline first.
  3. Select the INTERSECTING road centerline near the side that joins the main road.
  4. Allow the tool to find nearby generated road-edge geometry, or select the edge lines to clean when prompted.
  5. The tool creates curb-return geometry and trims/extends road-edge endpoints to the return tangent points.

The current implementation targets simple straight and curved-centerline cases first. Compound/reverse curve intersections and highly complex multi-leg layouts may require manual cleanup.

Command: CLV_SUBDIV_INTERSECTION

LOT LINES

  1. Select the source lot line to offset repeatedly.
  2. Pick the furthest point or stop location in the direction the lot lines should be generated.
  3. Enter the typical lot spacing/offset distance.
  4. Optionally select trim/extend boundary lot lines near the ends.

The tool creates repeated offsets until the selected stop location is reached. Straight offsets can be trimmed/extended to nearby lot or boundary lines. Curved-road fan layouts and other specialized lot patterns remain design-in-progress.

Command: CLV_SUBDIV_LOT_LINES

REVIEW NOTES

  • Subdivision tools are drafting helpers, not a substitute for final subdivision design review.
  • Run ROADS again after source centerline changes so generated road-edge geometry reflects the current centerlines.
  • Review tangent connections, trimming, gaps, and intersections after every generated subdivision operation.
