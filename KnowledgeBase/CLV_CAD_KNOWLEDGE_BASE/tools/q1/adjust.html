Q1 MENU

ADJUST

UFLS network adjustment, lateral creation, storm drain move, material swap, modify, info, and finalize tools.

SEWER MAIN - MOVE

Moves sewer structures and pipes to match UFLS generated linework.

Tool
Purpose
MH - SINGLE
Moves the selected sewer manhole to match generated 2D structure linework.
HOW TO
MH - ALL
Automatically moves all sewer manholes to match generated 2D structure linework.
HOW TO
PIPE - SINGLE
Moves the selected sewer pipe to match the generated UFLS 3D polyline.
HOW TO
PIPE - ALL
Moves all sewer pipes to match generated UFLS 3D polylines.

SEWER LATERAL PVC

Creates PVC sewer laterals from AEC survey points.

Tool
Purpose
LAT - SINGLE
Creates a sewer lateral from selected AEC points. Selection order should start from lot location and head towards sewer main. Merges the lateral into the existing project network.
HOW TO
LAT - ALL
Creates sewer laterals from all lateral points within a drawing. Returns redline clouds at areas that need user clarification.
HOW TO

SEWER LATERAL C900

Creates C900 sewer laterals from AEC survey points.

Tool
Purpose
LAT - SINGLE
Same as PVC version above, except pipe material is C900.
LAT - ALL
Same as PVC version above, except pipe material is C900.

STORM JUNCTION STRUCTURE

Resizes junction structures using generated structure linework.

Tool
Purpose
RESIZE JUNCTION
Uses structure linework created by INNER-STRUCTURE or OUTER-STRUCTURE routines. Allows user to select the structure and the structure linework to auto size the structure. The new part is added into the existing catalog as long as a part that size is defined in the master parts list.
HOW TO

STORM DRAIN - MOVE

Moves storm drain structures and pipes to match generated UFLS linework.

Tool
Purpose
JNCT - SINGLE
Moves and rotates the junction structure linework for selected object. Used to correctly position junction structures.
HOW TO
JNCT - ALL
Moves and rotates all junction structures automatically; requires no user input.
HOW TO
DI - SINGLE
Moves and rotates the selected drop inlet to the correct location based off the 2D linework. 2D linework must be generated using the UFLS tools.
HOW TO
DI - ALL
Moves all drop inlets to the correct location based off the 2D linework. 2D linework must be generated using the UFLS tools.
HOW TO
MH - SINGLE
Moves the selected access structure or circular manhole structures to match the 2D linework. 2D linework must be generated using the UFLS tools.
HOW TO
MH - ALL
Automatically moves all circular structures to align with the 2D linework. 2D linework must be generated using the UFLS tools.
HOW TO
PIPE - SINGLE
Moves the selected pipe to match the 3D polyline created using the UFLS tools. 3D linework must be generated using the UFLS tools.
HOW TO
PIPE - ALL
Moves all pipes to match the 3D polylines created using the UFLS tools. 3D linework must be generated using the UFLS tools.
HOW TO

SWAP MATERIAL

Swaps pipe material assignments for selected network objects.

Tool
Purpose
PVC --> C900
Swaps selected pipe material from PVC to C900 while keeping the network object in the project workflow.
HOW TO
RCP --> C900
Swaps selected pipe material from RCP to C900.
C900 --> RCP
Swaps selected pipe material from C900 to RCP.
C900 --> PVC
Swaps selected pipe material from C900 to PVC.

MODIFY

Maintenance tools for pipe network references.

Tool
Purpose
REMOVE REFERENCE ALIGN
Removes a reference alignment assignment from selected objects when a network cleanup requires it.

INFO

Review information from selected UFLS pipe and structure objects.

Tool
Purpose
PIPE INFO @ POINT
Allows user to select near a pipe, circular structure, or box structure and return information about the pipe nearest to the point of selection, such as material type, slope, invert, top of pipe, wall thickness, and pipe size. Useful when reviewing box structure runs.
HOW TO

FINALIZE

Final cleanup and quality assignment tools.

Tool
Purpose
ASSIGN QUALITY
Allows user to select quality level based on survey data type. Applies to all structures and pipes automatically.
