TOP CHECK

Compare the surveyed top-of-pipe elevation at a COGO point with the calculated Civil 3D pipe top, then prepare the checks for tolerance review and exhibit/table output.

LABEL

ELEVATION COMPARISON creates a structured Pipe Top Check label. The label stores the point, pipe, elevations, difference, station, offset, and display information as drawing metadata so later TOP CHECK tools can work from the stored check rather than parsing label text.

Label format
PLAN - TOP = elevation
SURV - TOP = elevation
DIFF = +/- difference

Basic workflow

  1. Select the Civil 3D COGO point used for the surveyed elevation.
  2. Select the Civil 3D pipe being checked.
  3. Specify the label location.
  4. Review the resulting PLAN - TOP, SURV - TOP, and DIFF values.

The surveyed elevation is the selected COGO point elevation. The plan top is calculated from the selected pipe at the picked location. DIFF = SURV - PLAN, so a positive value means the surveyed top is higher than the calculated plan top.

Command: UFLS-PIPE-TOP-CHECK

TOLERANCE CHECK

EXCEEDS TOLERANCE reviews every stored Pipe Top Check in the drawing against a user-specified tolerance. The default tolerance is 0.30.

What the command does

  • Prompts for the tolerance.
  • Identifies checks where the absolute difference exceeds the tolerance.
  • Assigns exhibit IDs to over-tolerance checks that do not already have one.
  • Changes over-tolerance checks to compact exhibit-number display.
  • Moves within-tolerance checks to V-SURV-CHCK-GOOD and turns that layer off.

This makes the drawing ready for an exhibit-style review where only the checks requiring attention remain visible by default.

Command: UFLS-PIPE-TOP-EXCEEDS-TOLERANCE

TABLE

TOP CHECK tables are linked to the structured Pipe Top Check data. They can be rebuilt from the stored checks and scaled to the current annotation scale.

Tool
Purpose
ADD TABLE
Select Pipe Top Check labels, then specify the table insertion point. Creates a table containing the selected checks.
ADD POINTS
Select an existing Pipe Top Check table, then select additional Pipe Top Check labels to add.
REMOVE POINTS
Select an existing Pipe Top Check table, then select Pipe Top Check labels to remove from the table.
SCALE TABLE
Updates Pipe Top Check tables to the current model annotation scale and refreshes their stored table data.

Commands: UFLS-PIPE-TOP-TABLE, UFLS-PIPE-TOP-TABLE-ADD, UFLS-PIPE-TOP-TABLE-REMOVE, UFLS-PIPE-TOP-TABLE-UPDATE

DISPLAY

Tool
Purpose
DETAILS
Restores all stored Pipe Top Check labels to detailed PLAN - TOP / SURV - TOP / DIFF display.
NUMBERS
Switches stored Pipe Top Check labels to compact exhibit-number display using their assigned exhibit IDs.

Commands: UFLS-PIPE-TOP-DETAILED and UFLS-PIPE-TOP-EXHIBIT

REQUIREMENTS AND NOTES

  • The surveyed check point must be a Civil 3D COGO point.
  • The pipe must be a Civil 3D pipe that can provide the required top-of-pipe calculation.
  • ELEVATION COMPARISON uses the CLV-Non Anno text style. If that style is missing, the command stops and the drawing should be loaded from the CLV template.
  • TOP CHECK labels are created on the managed UFLS Pipe Top Check layer and the command restores the user's original current layer afterward.
  • The check data is stored in the drawing on the MText object. Do not manually recreate the label as plain text if the check needs to participate in tolerance, table, or exhibit workflows.
