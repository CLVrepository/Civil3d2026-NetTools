CHECK

UFLS verification, redline, 2D linework, 3D linework, and pipe review tools.

VERIFICATION

Visual verification tools used during UFLS review.

Tool
Purpose
HIGHLIGHT RED
Highlights selected verification items in red for review and correction tracking.
HOW TO
HIGHLIGHT GREEN
Highlights selected verification items in green to show reviewed or accepted items.
HOW TO
OBJECT HIGHLIGHT RED
Highlights individually selected objects in red when only specific CAD objects need to be flagged for review.
HOW TO
OBJECT HIGHLIGHT GREEN
Highlights individually selected objects in green when only specific CAD objects need to be marked as reviewed or accepted.
HOW TO

REDLINE

Redline and callout tools for review comments.

Tool
Purpose
REVISION CLOUD
Creates a revision cloud for redline review. Prompts for Large, Medium, or Small size before running the cloud command.
HOW TO
NOTE
Adds a review note in the drawing.
LEADER
Adds a leader callout for review comments.

2D LINEWORK

Creates and marks structure linework used by later UFLS and network adjustment workflows.

Tool
Purpose
3P MANHOLE - ALL
Creates manhole linework from 3 AEC points, auto selected from descriptions. When using CLV surveyed data, the codes are automatic. If using others data, input the code manually as it varies from firm to firm.
HOW TO
3P MANHOLE - SINGLE
Creates manhole linework from one selected 3-point manhole point group.
HOW TO
1P MANHOLE - ALL
Creates manhole linework from a single AEC point identifying center of structure. When using CLV surveyed data, the codes used are automatic and diameter of block used will auto identify. When using others data, input the code manually since it varies from firm to firm.
HOW TO
1P MANHOLE - SINGLE
Creates manhole linework from one selected center point.
HOW TO
STRC-INNER WALL
Creates inner wall linework for a structure. Prompts for point selection and structure type to identify correct wall thickness. Once done, the outer wall offset happens automatically.
HOW TO
STRC-OUTER WALL
Creates outer wall linework for a structure. Prompts for point selection and structure type to identify correct wall thickness. Once done, the inner wall offset happens automatically.
HOW TO
STUB MARKER
Places or marks a utility stub location for UFLS review.
DROP INLET
Places a drop inlet structure block. User is prompted for structure type, structure size, and depth. User is prompted for 2 point back-of-curb shots only or 4 point outer limits of structure to identify placement. User is also prompted for a pick direction; select the direction of the centerline of road.
HOW TO
3P CIRCLE
Creates circular linework from three picked points.
3P RECTANGLE
Creates rectangular linework from picked points.

3D LINEWORK

Creates, trims, and labels 3D pipe review linework.

Tool
Purpose
TOP OF PIPE
Creates a best fit 3D polyline for the top of pipe from user selected AEC points.
HOW TO
TRIM TOP OF PIPE
Used to help trim linework when drawn past structure inner wall. Note: does not work well for circular manhole blocks.
HOW TO
LABEL INVERT
Labels the start invert and end invert of the 3D polyline. Used for review purposes.
HOW TO

INFO

Review information from selected UFLS pipe and structure objects.

Tool
Purpose
PIPE INFO @ POINT
Allows user to select near a pipe, circular structure, or box structure and return information about the pipe nearest to the point of selection, such as material type, slope, invert, top of pipe, wall thickness, and pipe size. Useful when reviewing box structure runs.
HOW TO
