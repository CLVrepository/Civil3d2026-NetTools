CLV Knowledge Base Custom SVG Icons

Use these as fixed image assets instead of regenerated inline/CSS/library icons.

Recommended folder:
assets/icons/

Recommended HTML usage:
<img class="card-icon" src="assets/icons/q1-ufls.svg" alt="UFLS tools icon">
